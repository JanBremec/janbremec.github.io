50+ teams. The top spots were hard earned. Ours included.

DCTF26 is an annual cybersecurity conference and Capture the Flag competition organized by DragonSec SI at the University of Ljubljana, Faculty of Computer and Information Science. This year's challenges covered the full spectrum — web exploitation, reverse engineering, hardware hacking, cryptography, and more. Not exactly a casual weekend activity, but we managed.

CTF competitions are about as close as you can get to real-world offensive security in a controlled environment. You're given systems, binaries, and devices — and your job is to break them before anyone else does. We did that.

Jan Bremec · 1st
AI Engineer & Software Developer · AdaHack 1st Place Winner
Hackathon Victory · 🌐
🏆 1st Place

Won the hackathon with a RAG-based learning tool built for real impact: full voice control and accessibility support for blind students. 🏆

Took on Abelium’s challenge and delivered a solution that exceeded functional demands and held up under technical scrutiny.

The system uses a FAISS vector database with hybrid retrieval combining semantic and keyword search. Speech-to-text handles all input, text-to-speech delivers responses, and Gemini generates answers grounded in retrieved context chunks. Added lecture transcription, AI-based document sorting by subject, and a fully navigable interface using arrow keys and shortcuts that announces the user’s position and enables viewing or listening to any document.

Thanks to Klub Ada for organizing the hackathon and Lea Vodopivec for contributing to the project.
